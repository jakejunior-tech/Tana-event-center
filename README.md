# Tana Event Center

Premium event venue website for **Tana Event Center**, located at 29 King
Perekule Street, GRA Phase II, Port Harcourt. Built with Next.js, TypeScript,
Tailwind CSS and Framer Motion in a luxury black &amp; gold theme.

## Sections

- Hero — full-screen image with slow zoom
- About Tana — "Where Beautiful Moments Begin" + feature cards
- The Venue — The Tana Experience + venue at a glance
- Event Types — one venue, every occasion
- Gallery — masonry gallery with lightbox
- Testimonials — client feedback + stats
- Plan Your Event — booking form that opens in WhatsApp
- Location — address + Google Maps embed
- Footer + floating WhatsApp button

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

```bash
npm run dev       # development server
npm run build     # production build
npm run start     # run production build
npm run lint      # lint
```
